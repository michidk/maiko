Play The Elder Scrolls Adventures: Redguard natively on Windows and Linux, with an experimental macOS port.

Requires your own copy of Redguard. Your executable stays on this device.

Build your package

Where will you play?

The macOS port is experimental. Mac packages currently need a local source build; this browser builder creates Windows and Linux packages.

The Mac runtime contains no original game assets. Supply your own Redguard installation, then open the universal redguard-native executable to select it. No command launcher is needed.

Mac build instructionsLaunch and logs

Select RGFX.EXE from your Redguard installation.

Download your ZIP


      

    

    
Once your ZIP is ready
  1. Extract it into its own folder, outside your game installation.
  2. On Windows, open RUN.cmd. On Linux, run ./RUN.sh /path/to/Redguard in a terminal.
  3. Saves and settings go into the package's user-data folder.
Prefer the terminal? Use the Rust command-line tool.
