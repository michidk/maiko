Play The Elder Scrolls Adventures: Redguard natively on Windows and Linux, with an experimental macOS port.

Requires your own copy of Redguard. Your executable stays on this device.

Build your package

Where will you play?

The macOS port is experimental. Your ZIP supports Apple Silicon and Intel Macs. Mac builds take longer and need a current desktop browser.

Select RGFX.EXE from your Redguard installation.

Once your ZIP is ready
  1. Extract it into its own folder, outside your game installation.
  2. For the pinned Windows package, open RUN.cmd. On Linux, run ./RUN.sh /path/to/Redguard in a terminal. Follow the included README for these runtime snapshots.
  3. Saves and settings go into the package's user-data folder.
Prefer the terminal? Use the Rust command-line tool.

    
Once your Mac ZIP is ready
  1. Extract the ZIP into its own folder.
  2. Open redguard-native. Select your owned Redguard installation if asked. The ZIP contains the runtime; you supply the game files.
  3. If macOS blocks the download, open Terminal and remove quarantine from the extracted folder:
    xattr -dr com.apple.quarantine "$HOME/Downloads/maiko-macos-universal"
    Adjust the path if you extracted it elsewhere, then open redguard-native again.
Saves and settings are in ~/Library/Application Support/Maiko/user-data. Logs are in ~/Library/Logs/Maiko. Read the Mac launch guide for details.
