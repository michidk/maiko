Play Redguard on
Windows or Linux.

The original adventure, running natively. Build a package from your own copy of the game, without DOSBox.

An experimental port

The opening and many locations work. A complete playthrough is still untested. You need to own Redguard and keep its original game files.

Build your package

Your file stays on this device.

Where will you play?

Find it inside your Redguard installation. Select only the executable. The other game files stay where they are.

Download your ZIP

Choose your executable to begin.


    

    
Once your ZIP is ready
  1. Extract it into its own folder, outside your game installation.
  2. On Windows, open RUN.cmd. On Linux, run ./RUN.sh /path/to/Redguard in a terminal.
  3. Windows asks for the original game folder. Linux uses the path you pass to RUN.sh and needs a working OpenGL driver; see the included README. Your saves and settings go into the package's separate user-data folder.
You can also build locally with the Rust command-line tool. macOS and mobile devices are not supported as game targets.
